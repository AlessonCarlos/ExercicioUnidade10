# Projeto TypeScript

Projeto feito para praticar alguns conceitos básicos de TypeScript.

## O que foi feito

* Variáveis
* Tipos (`string`, `number` e `boolean`)
* Type Alias
* Objetos com tipos
* `for`
* `while`
* Função com tipos

## Como executar

Primeiro instale as dependências:

```bash
npm install
```

Depois execute:

```bash
npm run dev
```
